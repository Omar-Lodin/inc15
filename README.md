# inc15
Critical thinking:
1.
The app will allow the user to continue answering questions in the current round while still providing answer feedback as to whether the choice was correct/incorrect. At the end of the round, the buttons for “Sync to cloud” and play again can be pressed, but pressing “sync to cloud” will change the color and text of the button to “Syncing to cloud”, but will not be successful until connection is reestablished. The “play again” button will show the spinning wheel animation and then display a connection error while there is no network connection, and this will remain until the app is restarted. 
2.
It would be useful to save the number of rounds completed with a score of “x / 5”, or “x out of 5” correct. So it would save how many rounds attempted with a score of 1 / 5, 2 / 5, 3 / 5, 4 / 5, and 5 / 5 correct. This would make it useful for the user to know what they scored overall while using the app without having to connect to a network to check their record. Local storage would be not make it a shared leaderboard since the data is not sent elsewhere to be stored and managed, rather it is done locally on the device’s storage that is handling the app.
